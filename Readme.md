# Flask Registration Form Project

## Project Description

This is a simple web application developed using the Flask framework in Python.
The application allows users to register by entering their personal details such as name, email ID, phone number, password, and confirm password. After submitting the form, the entered information is displayed on a confirmation page.

## Features

* User registration form
* Collects user information (Name, Email ID, Phone Number, Password)
* Password confirmation validation
* Displays registration details on a confirmation page
* Built using Flask and HTML templates

## Requirements

Make sure Python is installed on your system.

Install Flask using pip:

pip install flask

## How to Run the Application

1. Download or clone the project.
2. Open the project folder in a terminal or command prompt.
3. Run the Python file:

python "Registration Form.py"

4. Open a web browser and go to:

http://127.0.0.1:5000/register

## How the Application Works

1. The user opens the registration page.
2. The user fills in the required details.
3. After clicking the register button, the form data is sent to the Flask server.
4. Flask processes the data and sends it to the confirmation page.
5. The confirmation page displays the submitted user information.

## Technologies Used

* Python
* Flask
* HTML
* Jinja2 Templates
